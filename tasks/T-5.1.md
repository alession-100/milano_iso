# T-5.1 - Picking with hover highlight and info card

- **Phase / depends on:** Phase 5 / T-5.2 and T-5.3a merged. Runs in parallel with T-5.3b.

## Goal
Hovering a feature highlights it (desktop). Clicking or tapping it opens an info card with what the data says about it: name, type, height and height source. Stylised items are never presented as mapped features.

## Changes
1. **Picking.**
   - Raycast the tile meshes under the pointer and read `_feature_id` of the hit face, then look up the tile's feature-table row.
   - For instanced trees, use the `instanceId` row.
   - What can be picked:
     - **buildings:** yes;
     - **landmark details:** yes, but the selection is the **landmark** (`layer: 'landmark'`), never the detail;
     - **roads:** yes, shown as the street, with its name from `index.json` when an entry lists that `osm_id`;
     - **green, water, landuse:** yes, with their kind;
     - **mapped trees** (`decorative=false`): yes;
     - **fill trees** (`decorative=true`), **markings**: never. The ray passes through them to whatever lies behind, or picks nothing.
   - Picking must not add draw calls and must not run a permanent loop.
   - Hover raycasts are throttled to at most one per animation frame, and only while the pointer moves.
2. **Hover highlight** (pointer devices only).
   - Tint the hovered feature through the existing per-tile material lookup (ADR-0026), for example a highlight feature-id uniform per tile material.
   - No extra draw calls. Clear the highlight on pointer leave. A tint is not a new palette colour.
3. **Selection.**
   - A click or tap without drag calls `select({ ref, source: 'pick' })`. Use the existing control thresholds, so a pan never selects.
   - A click on empty ground or Escape calls `select(null)`.
   - The selected feature keeps a highlight while the card is open.
4. **Info card** (listens with `onSelect`, so a search hit from T-5.3b opens it too).
   - **Content:**
     - the name, verbatim, or a localized "Senza nome" / "Unnamed";
     - a localized type label (building type group, road class, green/water kind, tree);
     - height and height source for buildings and trees, with a human label for each `height_source` value (IT/EN), for example "rilievo DBT 2020" / "DBT 2020 survey", "OSM", "default stimato" / "estimated default";
     - the OSM link (`https://www.openstreetmap.org/<type>/<id>`) when an OSM id exists;
     - for landmarks, the name from `index.json` and a line that its added details are stylised (ADR-0028).
   - **Layout:**
     - desktop: a panel at the right side below the rotation buttons;
     - 412 px: a bottom sheet above the attribution.
     - It must not cover the attribution, the tile notice or the controls.
     - Close button, Escape to close, focus moves into the card on open and back on close.
     - Use a `role="dialog"` with `aria-labelledby`, non-modal, so the map stays usable.
   - **Search hits:** a `source: 'search'` selection whose tile is not loaded yet shows the index data first (name, kind) and fills in the rest when the tile arrives. It must not crash.
   - Every string goes through i18n (IT default, EN).
5. **Test hook.**
   - `registerTestState('selection', ...)` with the current ref and the card's visible fields.
   - A helper to pick at a screen point.
6. **Tests.**
   - Unit tests:
     - row lookup from feature id;
     - the not-pickable rules;
     - the height-source labels cover every `height_source` value in the fixture and in `pipeline/milano_iso` (grep the pipeline for the values).
   - e2e (fixture):
     - hover changes the highlight state;
     - clicking each building colour group shows its card with the right name and height;
     - clicking the landmark detail selects the landmark;
     - a fill tree is not pickable;
     - a drag does not select;
     - Escape closes and restores focus;
     - mobile tap works;
     - zero console errors.
   - Visual: hide the card in `e2e/visual-hide-controls.css` only if it would be open in a baseline view (it should not be). Add one new visual baseline: the card open on the fixture building B1 at both sizes (win32 only).

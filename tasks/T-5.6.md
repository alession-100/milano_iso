- **Phase / depends on:** Phase 5 / T-5.4 merged; G5 findings N3 and N6. Runs in parallel with T-5.5 (layout, card, toggle, layers). Do not touch `web/src/pick/`, `web/index.html` layout CSS, `web/src/toolbar.ts` layout, or the minimap.

## Goal
The search index must call each feature what the data says it is. Stop platforms named after a metro or tram stop must not show as "Via"/"Street". A search for a landmark's own name must show the landmark.

## Changes
1. **Index kinds (pipeline, ADR-0031 amendment as ADR-0033).**
   - A way tagged `public_transport=platform`, `highway=platform` or `railway=platform` is never part of a "street" entry. Give named platforms a new kind `stop` (IT "Fermata", EN "Stop"), grouped by exact name like streets, ref `{osm_ids}`.
   - Decide and document in ADR-0033 what else is not a street (for example `footway=sidewalk` ways named after something else; footways and steps that are not platforms). Base every rule on OSM tags or the road class, never on name patterns. Report the before/after count per kind on real data and list the entries that moved.
   - Streets that mixed platforms (Largo Augusto, Piazza Fontana, Via Larga) must have bbox and centre from their street ways only.
   - If the needed tags are not available where the index is built, carry the minimum tag (e.g. a boolean `is_platform`) through the pipeline; say where and why.
   - Determinism: sorted output, byte-identical on rebuild; new kind added at the end of `KIND_ORDER` (append-only, bump `INDEX_FORMAT_VERSION` if the client needs it).
2. **Client (web).**
   - `search.ts`: accept kind `stop`; map it to `FeatureRef` `{layer:'roads', osmType, osmId, streetName}` like streets (the card shows the real road class).
   - **Ranking (N6):** an exact folded-name match first; then landmarks before other kinds among prefix matches; then the existing order. "galleria" must list "Galleria Vittorio Emanuele II" within the 8 results; "duomo" lists "Duomo di Milano" first.
   - Kind labels: the landmark label in search matches the card's term (one term in each language). i18n for `stop` in both languages; the i18n tests stay green.
3. **Tests.**
   - Pipeline unit tests: a platform way (each of the three tags) never joins a street; a street with the same name as a platform keeps only its own geometry; byte identity of `index.json` on rebuild; fixture regenerates byte-identically (`tests/pipeline/test_fixture_tiles.py`).
   - Regenerate the fixture tiles' `index.json` only through the pipeline if the fixture outputs change; do not hand-edit.
   - Web unit tests: ranking (exact first, landmarks first among prefixes, deterministic), kind `stop` mapping. e2e: the fixture search shows the right kind label (if the fixture has no platform, a unit test is enough; say so).

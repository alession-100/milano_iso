- **Phase / depends on:** Phase 0 / T-0.2 (merged)
- **Owner:** executor

## Goal
Fix four non-blocking issues the G0 reviewer found in the scaffold, so CI stays reproducible and leaves the working tree clean.

## Inputs
- `CLAUDE.md`
- `Makefile`, `.gitignore`
- `.github/workflows/ci.yml`
- `web/e2e/smoke.spec.ts`, `web/playwright.config.ts`, any script that composes `side-by-side.png`
- `docs/DECISIONS.md` ADR-0012 (console filter rule)

## Outputs
- `Makefile`, `.gitignore`, `.github/workflows/ci.yml`, `web/e2e/*`, `web/playwright.config.ts`
- `reports/R-0.2a.md`

## Issues to fix
1. **Lockfile drift:** `make setup` runs plain `uv sync`, which can silently re-resolve the lock. Use `uv sync --locked` so a stale lock fails.
2. **e2e writes into a tracked folder:** e2e overwrites the committed PNGs in `reports/artifacts/T-0.2/`. Write e2e screenshots to a gitignored folder instead, default `web/e2e-output/`, overridable with env `E2E_OUT_DIR`. Leave the committed T-0.2 PNGs in place; they are historical evidence.
3. **Test order dependence:** the side-by-side compose test needs files from the first test. Make every e2e test independent, so each passes when run alone with `--grep`. One combined test is acceptable.
4. **CI token scope:** add a top-level `permissions: contents: read` block to `ci.yml`.
5. **Console filter (ADR-0012):** anchor the ignore regex so it matches only that driver message, not any text that contains it. Keep the exact wording of the message.

## Constraints
- No new dependencies. No version changes.
- Keep every existing check; do not weaken the console check beyond the ADR-0012 filter.
- Commit messages end with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.

## Out of scope
- `pipeline/`, `tests/`, `docs/`, `tasks/`, `reports/artifacts/T-0.2/`.

## Acceptance criteria
1. `grep -n "uv sync --locked" Makefile` matches.
2. `make setup && make test` exit 0.
3. `npm --prefix web run e2e` exits 0, then `git status --short` is empty, and the PNGs exist in `web/e2e-output/`.
4. Each e2e test passes alone: `npx --prefix web playwright test --grep "<title>"` for every test title (list the commands and results in the report).
5. `ci.yml` parses as YAML and contains `permissions:` with `contents: read`.
6. An injected `console.warn("probe")` in `web/src/main.ts` makes e2e fail (show it, then revert).

## Verification commands
```bash
grep -n "uv sync --locked" Makefile
make setup && make test
npm --prefix web run build && npm --prefix web run e2e
git status --short
ls web/e2e-output/
uv run python -c "import yaml; d=yaml.safe_load(open('.github/workflows/ci.yml')); print(d.get('permissions'))"
```

## Escalate if
- Playwright cannot make the tests independent without duplicating more than about 30 lines.
- `uv sync --locked` fails on the current lock.

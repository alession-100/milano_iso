## Changes
1. **Layout at every width (B1, N1, N1b).**
   - The minimap, attribution, toolbar panels (results, layers, help), tile notice, info card and right controls never overlap at any viewport size. Choose the simplest robust rule (for example: the attribution's left edge clears the minimap, or the minimap stacks above the attribution; panels and the card share space by a rule, not by fixed pixel offsets for two sizes). Short landscape heights (412 px) need a rule too (for example: collapse the minimap behind its button when the height is small, as at 412 px wide).
   - Add an e2e **width and height sweep** on the fixture: widths 360 to 1440 in steps of at most 40 px, plus 915x412, 768x1024, 800x728 and 1024x600; in the worst states (card + results + notice; card + layers; card + help; minimap open where it can be). Assert pairwise no overlap by bounding box, every block inside the viewport, no horizontal scroll, and `elementFromPoint` on each attribution link and each layer check box returns that element (or a descendant). Day and night only where the layout differs.
2. **Landmark card (N2).** Show what the data has for the landmark body: height and height source from the tile feature table of the landmark's body feature (DBT volume), and the OSM link if the landmark has an OSM id. Never show a stylised detail's numbers as data. If a landmark has no such data, show nothing (no placeholder number) and say so in the report. Unit and e2e tests on the fixture landmark.
3. **Toggle state (N4).** Make the pressed state distinguishable by more than fill (for example a check mark or icon, or a 3:1 change). Keep the ARIA toggle pattern. Do not change map colours (ADR-0030).
4. **Layers keyboard (N5).** Escape closes the Layers panel and returns focus to its button, as for Help. When the panel opens, the next Tab reaches its first check box. e2e.
5. **Reduced-motion inertia test (N7).** Make the test meaningful: prove frames were rendered after the release (for example wait for N rendered frames through the shared helpers in `e2e/support.ts`) before asserting nothing moved. No wall-clock asserts.
6. **Visual baselines.** Regenerate only the win32 baselines whose UI changed (delete first); prove the map pixels outside UI boxes are unchanged (`web/scripts/compare-baselines.mjs`). Leave `*-linux.png` alone.

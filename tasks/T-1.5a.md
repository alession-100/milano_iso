## Rule to implement
For an entry whose QID resolves only to a non-building element:
1. Take the closed `building=*` way or multipolygon relation that contains the QID's station node. Use Overpass `is_in`, or query `building` areas around the node and test containment yourself.
2. If exactly one building contains the node, use it. Record `osm.via: contains_node/<id>`.
3. If none or several contain it, keep the node fallback and report BLOCKED with the candidates.

Apply the rule only where it is needed (currently only `stazione_centrale`). Save the new responses next to the others, and make `fetch_landmarks.py` and `build_landmarks.py` handle the rule so that the YAML stays reproducible offline.

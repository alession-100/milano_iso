# T-7.1 - Accuracy audit: landmarks and 50 random buildings against the source data

- **Phase / depends on:** Phase 7. Independent of the host (T-7.0).
- **Owner:** reviewer. This is an audit, so the doer is not the checker: the reviewer finds and reports, and fixes nothing.
- **Output:** `reports/R-7.1.md`, written by the reviewer and committed by the orchestrator.

## Goal
Show with numbers that what the city build draws matches the source data, within the tolerances of `docs/VERIFICATION.md` section 3.

## What to check
1. **Landmarks.** Check all 16 entries of `tests/landmarks.yaml`, comparing the processed or rendered position with the source position. Tolerance: 5 m.
   - Name the source for each entry.
   - List `stadio_meazza` separately, with what is unresolved about it.
2. **50 random buildings** from the city's processed buildings. Draw them with a fixed seed, which you state, sorted by a stable ID.
   - Choose a selection that is stratified by height source and by district, and say how.
   - For each building, compare against the source feature (OSM, Overture or DBT, whichever `height_source` names):
     - footprint: the Hausdorff distance between processed and source, against the simplification tolerance for its level (ADR-0037: level 0 at 0.2 m; VERIFICATION: at most 0.5 m);
     - centroid offset;
     - `height_m` against the source value, or against the rule that produced it;
     - which tile it lands in, and that it appears exactly once.
3. **The tallest building.** Check its height for plausibility against a cited source (VERIFICATION section 3, Sanity).
4. **Attribution** is visible in the UI at 1280x720 and at 412x915, and names every source in `docs/DATA_SOURCES.md` whose licence asks for it.

## Pass rule
- Every landmark is within 5 m.
- At least 49 of the 50 buildings are within tolerance on footprint and height, and every failure is explained.
- The tallest building is plausible, with a cited figure.
- Attribution is complete.

Report PASS, PASS WITH RISKS or FAIL, with a table per item and every figure traceable to a file or a command.

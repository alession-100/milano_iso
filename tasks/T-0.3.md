# T-0.3 - Data source audit, map origin and hosting limits

- **Phase / depends on:** Phase 0 / T-0.1 (ADRs accepted)
- **Owner:** executor
- **Branch:** t-0.3

## Goal
For every source in `docs/DATA_SOURCES.md`, confirm its URL, format, licence text, size and date from the provider's own pages, so no "TO VERIFY" remains. Also record the cited map origin (Duomo) and pilot AOI bbox required by ADR-0004, and the GitHub Pages limits needed by ADR-0005.

## Inputs
- `CLAUDE.md`
- `docs/DATA_SOURCES.md` (the file you update)
- `docs/DECISIONS.md` : ADR-0004 (origin and AOI), ADR-0005 (GitHub Pages), ADR-0009 (licences)

Tools: `curl` in Bash for web pages and APIs; `uv run --no-project --python 3.12 --with pyproj python ...` for coordinate transforms. Always send a generic User-Agent: `curl -A "milano-iso-audit/0.1"`. Do not put any personal data (names, emails) in requests. Respect rate limits: at most one request per second to Nominatim and Overpass, and as few requests as possible.

## Outputs
- `docs/DATA_SOURCES.md` (update the table and add the sections below; keep the existing "Height fallback chain" and "Data hygiene" sections unchanged)
- `reports/artifacts/T-0.3/` : evidence files (saved HTTP headers, API JSON responses, a short `evidence.md` index mapping each claim to its file or URL). Save licence pages as fetched HTML or text only if under 1 MB; otherwise save headers and the URL.
- `reports/R-0.3.md` (from `reports/_TEMPLATE.md`)

## What to record
For each source row: (a) exact download/API URL, (b) format, (c) licence name **and** the URL of the licence statement on the provider's site, with a short quote (under 15 words) of the key licence sentence, (d) size of the file(s) we would download (from HTTP `Content-Length` via `curl -sI`, or the provider's listing), (e) dataset date or version as stated by the provider, (f) retrieval date (today's date as shown by `date -u`).

Sources:
1. **OpenStreetMap.** Find the smallest Geofabrik extract that contains Milan (check the Geofabrik Italy page); record its URL, size and timestamp. Record the OSM licence page (ODbL) and the required attribution wording from osm.org/copyright.
2. **Overture Maps buildings.** Latest release identifier, access method (S3/Azure path, GeoParquet), licence of the buildings theme, and, from Overture's own documentation, which upstream sources the building heights come from (in particular whether they are derived from OSM). This affects whether step 4 of the height fallback chain adds information.
3. **Geoportale Lombardia, DBT (Database Topografico).** Dataset page for Milan / the province, format, licence, and the name of the attribute(s) holding building height or elevation (from the provider's data specification). State whether Milan city is covered.
4. **Comune di Milano open data.** The administrative boundary of the comune (and, if present, green areas). Record the dataset URL on the comune's open-data portal (CKAN API is acceptable), format, licence.
5. **DTM:** confirm it stays out of scope for v1; record only the provider URL and licence if quickly found, otherwise leave as "out of scope, not audited".

Additionally add these sections to `docs/DATA_SOURCES.md`:
- **"Map origin and pilot AOI (ADR-0004)"**: the Duomo di Milano position from (i) the OSM element for the cathedral building (element type and ID, its centroid computed from the geometry returned by the Overpass API) and (ii) Wikidata (QID and coordinate property P625). Report both in WGS84 and EPSG:32632, the distance between them in metres, and the origin = the OSM centroid in EPSG:32632 rounded to whole metres. Then the AOI bbox = origin +/- 500 m (xmin, ymin, xmax, ymax in EPSG:32632, plus the same corners in WGS84). Commit the script that computes these numbers as `pipeline/scripts/origin_from_sources.py` (stdlib + pyproj only; it reads the saved JSON responses from `reports/artifacts/T-0.3/` and prints the values).
- **"Hosting limits (ADR-0005)"**: GitHub Pages limits on published site size, file size, bandwidth and builds, and whether custom headers are supported, each quoted from docs.github.com with the URL.

## Constraints
- Never fill a value from memory. Every value has a URL or an evidence file. If a value cannot be found, write `NOT FOUND (tried: <urls>)` instead of guessing.
- Do not download full datasets (nothing over 5 MB). HEAD requests and small API calls only.
- Licence quotes under 15 words each.
- Commit on branch `t-0.3`; commit messages end with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.

## Out of scope
- Creating any pipeline code other than `pipeline/scripts/origin_from_sources.py`.
- Editing ADRs or any file other than the outputs listed.
- Deciding which source to use (report findings and recommendations in the report; the orchestrator decides).

## Acceptance criteria
1. `grep -c "TO VERIFY" docs/DATA_SOURCES.md` prints `0`.
2. Every source row has URL, format, licence name + licence URL, size (or `NOT FOUND` with tried URLs), dataset date, retrieval date.
3. The origin section lists the OSM element ID, the Wikidata QID, both coordinates in WGS84 and EPSG:32632, their distance in metres, the rounded origin and the AOI bbox.
4. `uv run --no-project --python 3.12 --with pyproj python pipeline/scripts/origin_from_sources.py` reproduces exactly the origin and bbox numbers written in `DATA_SOURCES.md`.
5. The hosting section quotes each GitHub Pages limit with its docs URL.
6. `reports/artifacts/T-0.3/evidence.md` maps every claim to a file or URL.
7. `git status --short` empty; work committed on `t-0.3`.

## Verification commands
```bash
grep -c "TO VERIFY" docs/DATA_SOURCES.md
uv run --no-project --python 3.12 --with pyproj python pipeline/scripts/origin_from_sources.py
ls -la reports/artifacts/T-0.3/
cat reports/artifacts/T-0.3/evidence.md
git status --short
```

## Escalate if
- A source's licence is unclear, missing, or appears incompatible with ODbL-based tiles or public hosting.
- The OSM and Wikidata Duomo positions differ by more than 50 m.
- A provider blocks automated access (do not work around blocks; report them).
- A required value cannot be found after trying the provider's main pages and API.

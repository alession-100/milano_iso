- **Phase / depends on:** Phase 0 / T-0.1 (ADRs accepted)

## Goal
Create the project skeleton (Python pipeline package, Vite + TypeScript + Three.js web client, Makefile, lint/test tooling, CI workflow) and render a hello-world scene with the orthographic camera, including a side-by-side comparison of the two candidate camera elevations.

## Constraints
- **Pinning (hard rule 5):** every Python and npm dependency pinned to an exact version (no `^`, `~`, `>=` ranges in `package.json`; `==` pins or a lockfile-enforced resolution in `pyproject.toml`). Use current stable releases and list every chosen version in the report.
- Python deps: geopandas, shapely, pyproj, pyogrio (runtime); pytest, ruff (dev). Use `requires-python = ">=3.12,<3.13"`.
- Web deps: three, vite, typescript, vitest, @playwright/test, eslint (+ typescript-eslint), @types/three.
- **Makefile** (must work in Git Bash on Windows and in bash on ubuntu CI; recipes call `uv run ...` and `npm --prefix web ...`):
  - `make setup` : `uv sync` + `npm --prefix web ci`
  - `make lint` : `ruff check` + `ruff format --check` on `pipeline/` and `tests/`
  - `make test` : `make lint` + `pytest` + web `typecheck`, `lint` and `test` (vitest). Must exit non-zero if any step fails.
  - `make data` and `make tiles` : placeholders that print `not implemented yet (Phase 1/2)` and exit 0.
- **npm scripts in `web/package.json`:** `dev`, `build`, `preview`, `typecheck` (`tsc --noEmit`), `lint`, `test` (`vitest run`), `e2e` (`playwright test`).
- **Camera (`src/camera.ts`):** a Three.js `OrthographicCamera`, azimuth 45 degrees, elevation from a single exported constant `DEFAULT_ELEVATION_DEG = 30`. The elevation can be overridden with the URL query `?elev=<degrees>`, accepting only `30` or `35.264` (anything else falls back to the default). Export a pure function that returns the camera direction vector for (azimuth, elevation) so it can be unit-tested.
- **Scene:** a flat 10 x 10 ground grid (1 unit = 1 m) and three plain boxes of different sizes; one directional light plus ambient light; flat shading; fixed colours. No external assets, no network requests, no randomness.
- **Unit tests (vitest):** at least (a) camera direction vector for elevation 30 and 35.264 degrees matches the expected trigonometric value within 1e-9, (b) `?elev` parsing accepts the two allowed values and rejects others, (c) `i18n.ts` has the same key set for `it` and `en`, and `it` is the default.
- **i18n (`src/i18n.ts`, ADR-0006):** dictionary with `it` and `en`; at minimum the page title and the attribution placeholder string. Show the attribution placeholder text in the page corner (the real attribution comes later).
- **e2e (`e2e/smoke.spec.ts`):** loads the built app (`vite preview`) in Chromium, asserts a `<canvas>` is present and that there are zero console errors and warnings, and saves screenshots at `?elev=30` and `?elev=35.264` at viewport 1280x720 to `reports/artifacts/T-0.2/`. Produce `side-by-side.png` (the two images next to each other, each labelled with its angle) with a script committed in the repo (for example a Playwright page that composes them, or a small Node script). Do not hand-edit images.
- **CI (`.github/workflows/ci.yml`):** on push and pull_request, ubuntu-latest: install uv, Python 3.12 and Node 24; `make setup`; `make test`; `npm --prefix web run build`; install Playwright Chromium; `npm --prefix web run e2e`. Pin action versions to a major tag (for example `actions/checkout@v4`).
- Line endings LF (`.gitattributes` enforces this).
- Commit on branch `t-0.2` in small commits. Commit messages end with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.

## Acceptance criteria
1. `make setup` exits 0 from a clean clone.
2. `make test` exits 0; output shows ruff, pytest (>= 1 test passed), tsc, eslint and vitest (>= 3 tests passed) all running.
3. Breaking a test makes `make test` exit non-zero (show this once in the report, then revert).
4. `npm --prefix web run build` exits 0; report the gzip size of the JS bundle (must be <= 600 KB per VERIFICATION.md section 5).
5. `npm --prefix web run e2e` exits 0 with zero console errors/warnings.
6. `reports/artifacts/T-0.2/elev-30.png`, `elev-35.264.png`, `side-by-side.png` exist and visibly differ in camera elevation.
7. `make data` and `make tiles` exit 0 with the placeholder message.
8. `package.json` has no version ranges: `grep -E '"[\^~]' web/package.json` prints nothing.
9. `.github/workflows/ci.yml` is valid YAML (`uv run python -c "import yaml,sys; yaml.safe_load(open('.github/workflows/ci.yml'))"` or equivalent) and contains the steps listed above.
10. `git status --short` is empty at the end; all work is committed on `t-0.2`.

## Escalate if
- A pinned version cannot be installed on Windows or ubuntu (for example a missing geospatial wheel for Python 3.12).
- `make` recipes cannot be written to work in both Git Bash and ubuntu bash.
- The e2e cannot run headless Chromium on this machine.
- Any criterion above cannot be met as written.

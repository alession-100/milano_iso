# T-6.10 - Apply ADR-0044 to the memory scripts

- **Phase / depends on:** Phase 6 follow-up, after T-6.9 merged. The owner accepted ADR-0044 on 2026-11-24.
- **Owner:** executor
- **Branch:** t-6.10

## Goal
The memory scripts gate what ADR-0044 says, and nothing else.
- **`npm run memory` (Playwright):** it passes on a clean run of any length. The renderer-process figure is information only, under a ceiling.
- **The run without the driver:** it gates the renderer process.

## Changes
1. **`web/scripts/memory-analysis.mjs` (the Playwright session).**
   - The renderer-process check stops deciding pass or fail. It is reported as information, labelled as including the driver's network agent.
   - It fails only if the renderer exceeds the ceiling of ADR-0044 (b): 250 MB per hour, a fitted slope of 4.2 MB/min after warm-up.
   - Heap, external memory, object counts, DOM nodes and programs keep their ADR-0043 limits, unchanged.
2. **`web/scripts/memory-nodriver.mjs`: add a pass rule as ADR-0044 (a) states it.**
   - The run is invalid unless every sample is `visible` and the run lasts at least 20 minutes.
   - The frame count is within 25 % of a reference figure. Use the frames of `reports/artifacts/T-6.9/playwright2_path_closed_20min.json` scaled to the run length, or an option to pass another reference.
   - The renderer slope from minute 20 is at most 1 MB/min.
   - It exits 1 on failure and writes an `analysis` block.
3. **Re-judge the saved runs** without re-running them, and list the results in the report:
   - with the new Playwright rule: `reports/artifacts/T-6.8/memory_60min.json`, `reports/artifacts/T-6.7/memory_20min.json`, `memory_5min_run1.json`, `memory_5min_run2.json` and `memory_leak_check.json` (the leak must still fail);
   - with the no-driver rule: `reports/artifacts/T-6.9/nodriver2_closed_60min.json`, and the withdrawn hidden-tab run `superseded_*`, which must come out invalid.
4. **Docs.** Add one line to the ADR-0044 status saying where the rule now lives, and mention both scripts in `docs/VERIFICATION.md` if it describes the memory check.

2. **Unit test:** a vitest, or a node test in the existing style, feeds `memory-analysis.mjs` and the no-driver rule small synthetic sample sets and covers:

   - 5 MB/min with the driver attached, which fails the ceiling;

# T-2.2 - Tile mesh export (binary glTF per 500 m tile) with feature tables

- **Phase / depends on:** Phase 2 / G1 passed, ADR-0021. Runs in parallel with T-1.7 (no shared files).

## Goal
Turn `processed/pilot.gpkg` into one deterministic `.glb` per 500 m tile, plus a sidecar feature table, as specified in ADR-0021. Each tile must load in a Node test script with three.js `GLTFLoader`.

## Specification (ADR-0021, made concrete)
- **Tile id:** `i = floor((E - E0) / 500)`, `j = floor((N - N0) / 500)`, file name `"{i}_{j}"`, using negative numbers as is (for example `-1_0`).
- **Buildings:**
  - Assign each `buildings` row whose `rendered` is true to the tile of `representative_point()` of its footprint. All of its `render_volumes` go to that tile.
  - Simplify each volume footprint with tolerance 0.2 m (`preserve_topology=True`). Assert that the Hausdorff distance to the original is <= 0.5 m, and record the max.
  - Extrude walls from `bottom_m` to `top_m`, add a flat top cap (triangulate with holes: use shapely's `triangulate` constrained to the polygon, or an ear-clipping implementation, with tests), and add a bottom cap only if `bottom_m > 0`.
  - Use flat normals per face (duplicated vertices), with consistent counter-clockwise winding seen from outside.
- **Flat layers:**
  - Clip each layer to the tile box and triangulate it.
  - Roads and rail become ribbons: a buffer of the line by half the width, with flat caps and a mitre limit, then triangulated. Width is the parsed OSM `width_raw` (metres) when valid, else the class width from `style.py`.
  - Y heights per layer come from `style.py` (for example green < water < road_areas < roads < rail, all < 0.3 m).
- **Mesh and file layout:**
  - One glTF mesh per non-empty layer, named exactly after the layer.
  - Attributes: `POSITION` (float32, with min and max set as glTF requires), `NORMAL` and `_FEATURE_ID` (uint32 for buildings; flat layers get the row index of their feature table).
  - Indices are uint32.
  - No materials beyond a single default material per mesh named after the layer. The asset generator is `milano-iso`; there are no timestamps.
- **Coordinates:** x = E - E0, y = height, z = -(N - N0), computed in float64 and cast to float32 last.
- **Feature table `<i>_<j>.json`:**
  - `{"tile": "...", "layers": {"buildings": [ {key, name, building_type, height_m, height_source, landmark_id}, ... ], "roads": [ {osm_id, class, name?}, ...], ...}}`.
  - Sorted keys, compact separators, UTF-8, LF line endings.
- **Determinism:** sorted iteration everywhere, no dict-order or set-order dependence, no timestamps. Two runs give byte-identical `.glb` and `.json`.

## Measurements to report (`export_summary`)
For every tile:
- the counts per layer (features, vertices, triangles);
- the `.glb` byte size, its gzip size at level 9, and its brotli size if Python's `brotli` happens to be available (do not add it as a dependency);
- the maximum Hausdorff distance from simplification.

Also report the total, a check that the number of buildings over all tiles equals the number of rendered buildings, and that no building appears in two tiles. Compare the gzip sizes to the 250 KB budget, and report it as a finding if a tile exceeds it.

## Acceptance criteria
1. `make tiles` writes 4 tiles (`-1_-1`, `-1_0`, `0_-1`, `0_0`), each with `.glb` and `.json`.
2. `node web/scripts/load-tiles.mjs <tile dir>` loads all 4 without errors and prints the counts. They equal `export_summary.json`.
3. Two `make tiles` runs give an identical sha256 for every file; show them.
4. The maximum simplification Hausdorff is <= 0.5 m (report the value).
5. The building count over the tiles equals the rendered buildings in `buildings`, and no building appears twice.
6. Unit tests cover:
   - tile id at boundaries (exactly on a tile edge, negative coordinates);
   - extrusion of a square with a hole: the vertex and triangle counts and the outward normals;
   - a bottom cap only when `bottom_m > 0`;
   - ribbon width from a tag vs from the style table;
   - a glb round-trip, with header, chunk alignment and accessor min/max checked by parsing it back in Python.
7. `make test` exits 0; `git status --short` empty; committed on `t-2.2`.

## Escalate if
- Any tile is above 250 KB gzip. Report it; do not change the tile size yourself.
- `GLTFLoader` cannot run in Node without a new dependency.
- Simplification at 0.2 m gives a Hausdorff > 0.5 m for any feature.

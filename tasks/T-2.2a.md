## Changes (ADR-0022 points 1-5)
1. Remove `NORMAL` and build indexed meshes with shared vertices. Keep the winding counter-clockwise from outside, so derivative-based flat normals face outward.
2. `KHR_mesh_quantization`, listed in `extensionsUsed` and `extensionsRequired`. int16 `POSITION` in centimetres relative to the tile centre at y = 0, with the node translation set to the tile centre in client metres and the node scale to 0.01. Accessor min/max are in the quantised units, as glTF requires. Out-of-range values raise an error.
3. uint16 indices when a mesh has fewer than 65,536 vertices, otherwise split it into `<layer>#<n>` meshes. `_FEATURE_ID` is uint16 when the tile has fewer than 65,536 features, else uint32. Keep glTF's 4-byte accessor alignment rules.
4. Export all tiles containing a rendered building's representative point (point 5), so every rendered building is in exactly one tile. Flat layers are clipped to the processed extent and to their tile.
5. Update `load-tiles.mjs`:
   - assert that the dequantised positions match the pipeline's float64 coordinates within 0.01 m, using a sample of at least 100 vertices per tile that the exporter writes to `export_summary.json`;
   - assert `KHR_mesh_quantization` is present;
   - report the counts.

## Amendment (retry 2/2, 2026-11-16)
After the first attempt was blocked (seven buildings more than 327.67 m from their tile centre; worst 358.9 m), ADR-0022 point 2a sets the unit to **2 cm** (node scale 0.02, range +/-655.34 m from the tile centre). Change 2 and the loader's position check now use that unit. The position tolerance becomes 0.011 m (1 cm rounding plus float slack). Report the worst overhang and the remaining headroom.

2. `node web/scripts/load-tiles.mjs` loads every tile, with 0 count mismatches and the position check passing.

4. Report every tile's gzip-9 size. A tile above 256,000 bytes is a finding: report it and do not change the tile size (that is the next ADR step).
5. Unit tests:
   - round-trip a quantised glb in Python, including the dequantisation error;
   - an out-of-range coordinate raises;
   - the index type switches at 65,536;
   - a shared-vertex extrusion of a square gives 8 vertices and 10 triangles (with a top cap, no bottom cap).
6. `make test` exits 0; `git status --short` empty; committed on `t-2.2a`.

## Changes
1. **Tile size.** Add `TILE_SIZE_M = 250` to `config.py`. `tiles/grid.py` and every other use read it from there; no literal 500 or 250 anywhere else (grep proves it). Update the tests to 250 m boundaries.
2. **Manifest.** Write `tiles.json` next to the tiles, plus a committed JSON Schema at `pipeline/milano_iso/tiles/tiles.schema.json` (draft 2020-12). Contents:
   - `format_version`, `crs` (`EPSG:32632`), `origin` {e, n} (from config), `tile_size_m`, `axis` (`x=E-E0, y=up, z=-(N-N0)`), `quantization` {unit_m: 0.02, anchor: "tile_center"}, `layers` (the list of layer names);
   - `attribution`: a list of {source, licence, text} for OSM (ODbL, "(c) OpenStreetMap contributors") and Comune di Milano DBT 2020 (CC BY 4.0). The text comes from `docs/DATA_SOURCES.md`; quote what is there, do not invent wording;
   - `tiles`: a list sorted by id, each with `id`, `i`, `j`, `bbox_local` [xmin, zmin, xmax, zmax], `bbox_epsg32632` [e0, n0, e1, n1], `counts` per layer, `glb` {file, bytes, gzip9_bytes, sha256} and `features` {file, bytes, sha256};
   - `totals`.

   It must be deterministic: sorted keys, LF, no timestamps.
3. **Checks in a pytest data test** (marker `data`, so `make test` is unchanged):
   - the manifest validates against the schema (use `jsonschema` only if it is already installed; otherwise write a small validator for the subset used, with tests);
   - the tile bboxes have no gaps or overlaps (they tile the grid exactly);
   - the sum of the tile counts equals the manifest totals and the processed source counts;
   - every rendered building is in exactly one tile;
   - every tile's gzip-9 size is <= 256,000;
   - the sha256 values in the manifest match the files.
4. **`make check-tiles-determinism`** (in `pipeline/mk/50-tiles.mk`): exports twice into two scratch dirs and compares every file byte for byte, `tiles.json` included. It exits non-zero on any difference.
5. **glTF validation.** Add `gltf-validator` (the Khronos package on npm) as an exact-pinned devDependency in `web/`, with `web/scripts/validate-tiles.mjs`, which runs it on every `.glb` and fails on any error. Warnings are listed in the report. This settles the open question about `byteStride` and alignment.

6. `make test` exits 0; `git status --short` empty; committed on `t-2.3`.

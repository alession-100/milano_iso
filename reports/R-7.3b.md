## Documentation (fetched with curl, generic User-Agent, 2026-11-25)
Workers static assets headers, https://developers.cloudflare.com/workers/static-assets/headers/ (markdown view `.../index.md`):
- "The default response headers served on static asset responses can be overridden, removed, or added to, by creating a plain text file called `_headers`". "Headers defined in the `_headers` file override what Cloudflare ordinarily sends."
- Default `Content-Type`: "attached to the response if one is provided during the asset upload process ... Wrangler automatically determines the MIME type of the file, based on its extension."
- Detach: "prepending the header name with an exclamation mark and space (`! `)"; "`!` removes only what earlier rules have already added", so the narrower rule goes after the broader one.
- Joining: "If a header is applied twice in the `_headers` file, the values are joined with a comma separator." "Rules are applied in the order they appear in the file." Limits: up to 100 header rules; 2,000 characters per line.
- Whether `Content-Type` specifically may be overridden by `_headers`: NOT FOUND (the page only says default headers can be overridden; it gives no `Content-Type` example). Hence both the plain and the detach variants.
Compression page, https://developers.cloudflare.com/speed/optimization/content/compression/ (markdown view): the list includes `application/json`, `application/wasm`, `text/plain` and others; no `model/gltf-binary`. Whether that zone page governs Workers static assets responses: NOT FOUND there (R-7.3a showed JSON, SVG and JS are compressed on this host).
The experiment uses 5 general rules plus 8 variants (13 blocks) (well under 100 rules).

**`tiles.json`** (gzip request): `Cache-Control: no-cache` only (was `immutable, no-cache` in R-7.3a); `Content-Type: application/json`, compressed. Fix confirmed.

## Open questions and risks
- If `Content-Type` in `_headers` is joined rather than replaced, the response carries two comma-joined values (e.g. `model/gltf-binary, application/json`) and the edge may not compress; the detach variants test that.

- **Status:** PARTIAL (all criteria met except the size budget: tile 0_0 is 287,667 bytes gzip-9, above 256,000; a finding per criterion 4)

## What changed
- `pipeline/milano_iso/tiles/geom.py`: indexed meshes with shared vertices, no normals, counter-clockwise winding; `to_gl_chunks()` splits at 65,535 vertices.
- `pipeline/milano_iso/tiles/glb.py`: int16 `POSITION` in 2 cm units from the tile centre (ADR-0022 point 2a), node translation = tile centre and scale 0.02, `KHR_mesh_quantization` used and required, accessor min/max in quantised units, out-of-range raises, uint16/uint32 index and `_FEATURE_ID` by 65,536.
- `pipeline/milano_iso/tiles/export.py`: every tile holding a rendered building's representative point is exported; flat layers clipped to the processed extent and tile; stale files removed first; summary gets `position_sample` (128 vertices per tile), before/after gzip column, `max_offset_from_centre_m` and a headroom line.
- `web/scripts/load-tiles.mjs`: sums `<layer>#<n>` chunks, asserts the extension, dequantises via the node matrix and checks the sample (tolerance 0.011 m, sample >= 100), reports counts.
- `tests/pipeline/test_glb.py`, `tests/pipeline/test_tiles_geom.py`: new tests.
- `reports/artifacts/T-2.2/export_summary.{json,md}`: regenerated.

## Deviations and assumptions
- 2 cm unit and 0.011 m tolerance per the orchestrator's amendment (ADR-0022 point 2a).
- `byteStride` 8 on the int16 `POSITION` view (2 padding bytes per vertex) to keep vertices 4-byte aligned; `_FEATURE_ID` and indices are tightly packed. No glTF validator was available to confirm.
- Unsplit meshes keep the name `<layer>`; `#<n>` only when a layer is split. No layer on this data exceeded 65,535 vertices in a way that was checked beyond the loader's count match (which sums chunks), so the chunk path is exercised by a unit test only.
- Greedy chunk split between triangles, so a building can straddle two chunks.
- Brotli stays optional and absent (no new dependency).
- The exporter now always exports outside tiles (the `--include-outside` flag was removed).
- `load-tiles.mjs` header gained `Buffer` as a lint global.

## Open questions and risks
- Tile 0_0 exceeds the 250 KB budget: the orchestrator decides the next ADR step (250 m tiles, per ADR-0022 point 4).
- Positions now carry 1 cm rounding error (2 cm quantum); well below the 0.5 m simplification tolerance.

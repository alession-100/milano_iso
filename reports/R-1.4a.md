# R-1.4a - Default height from minor buildings; roofs and construction sites not rendered

- **Status:** DONE (not self-signed; orchestrator to verify)
- **Branch / commits:** `t-1.4a`; see `git log t-1.4a` (one implementation commit, one report commit)

## What changed
- `pipeline/milano_iso/heights.py`: per-type default logic (`derive_defaults`, `MIN_N_FOR_TYPE_DEFAULT`) removed. New `derive_default` = median `height_m` of DBT buildings with `building_class == "EDI_MIN"`; raises `ValueError` if there are none (no fallback). New `render_status` and columns `rendered` / `render_reason` on `buildings`, `render_volumes` and `unmatched_osm.csv`. `heights.md` / `heights.json` gain rendered / not-rendered counts and the default. Also fixed a variable shadowing (`reason` in the parse-log loop) that I noticed while testing.
- `tests/pipeline/test_heights.py`: per-type default tests replaced with tests for the new rule (median, loud failure with no `EDI_MIN`, missing column), `render_status`, and the synthetic end-to-end build (roof, construction, default rows).
- `reports/artifacts/T-1.4/*` regenerated.

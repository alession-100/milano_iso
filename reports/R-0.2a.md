## Deviations and assumptions
- The real Chromium message is `[.WebGL-0x<hex>]GL Driver Message (OpenGL, Performance, GL_CLOSE_PATH_NV, High): GPU stall due to ReadPixels` (observed in a failing run). A regex anchored on only the bare phrase would reject it, so the anchored regex includes the full observed prefix: `/^\[\.WebGL-[0-9a-fx]+\]GL Driver Message \(OpenGL, Performance, GL_CLOSE_PATH_NV, High\): GPU stall due to ReadPixels$/`. The phrase itself is unchanged.
- I did not edit `docs/DECISIONS.md` (out of scope); ADR-0012 describes the filter as the bare phrase, so the orchestrator may want to update its wording.
- Running playwright from the repo root with `--config` wrote to `./e2e-output` (cwd based); I deleted that stray folder. The `E2E_OUT_DIR` override is supported but I did not exercise it.

## Open questions and risks
- The message includes the driver token `GL_CLOSE_PATH_NV`, which may differ on other CI machines; if CI fails on that, a new ADR is needed to widen the filter.

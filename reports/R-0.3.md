## Key findings (for the orchestrator)
1. **OSM:** Geofabrik Nord-Ovest (595,473,987 bytes, data to 2026-11-14T21:20:41Z) is the smallest extract; ODbL.
2. **Overture:** release 2026-10-21.0, buildings licence ODbL; primary source is OSM with the highest priority, so Overture height (chain step 4) mostly repeats OSM and adds information only for non-OSM buildings.
3. **DBT:** the Comune di Milano itself publishes the DBT 2020 (CC BY, 596,533,009 bytes ZIP, flight 2020). Height attribute is `UN_VOL_AV` ("altezza volume") on class `UN_VOL`; confirmed in the real file (237,743 records, all with a value, median 13.2 m, max 200.7 m). The regional Socrata portal only has Lecco and Sondrio DBT buildings. Milan is covered in the regional DBGT progress list.
4. **Comune boundary:** GeoJSON, 1.9 MB, CC BY.
5. **Hosting:** 1 GB published site, 100 GB/month soft bandwidth, 10 builds/h soft (not applied to custom Actions workflows). Full-city tiles must stay under 1 GB.

## Deviations and assumptions
- The OSM centroid is computed from the multipolygon relation (88 outer ways joined into rings, area-weighted centroid in EPSG:32632). The cathedral is a relation, not a way; I used it as the "OSM element for the cathedral building" (it carries `wikidata=Q18068`, `building=cathedral`).
- Overpass requests: 3 (one mistaken query with output discarded, one global `wikidata=Q18068` query that returned HTTP 502, one bbox-limited query that succeeded; the bbox used a margin around the Wikidata point only to limit the search). The Q18068 QID was found by Wikidata's search API, then confirmed by the OSM `wikidata` tag.
- Geofabrik "smallest extract" judged from the region listing; Milan inside the Nord-Ovest polygon was not tested.
- DBT: read `UN_VOL.dbf` (4 MB compressed) from the Comune ZIP using HTTP range requests, plus the 1.9 MB regional schema zip, kept only in a scratch directory. No full dataset was downloaded. The probe script is stored in the artifacts folder as evidence, not as pipeline code.
- Licence: the Comune portal's CKAN says "Creative Commons Attribution" (no version); CC BY 4.0 comes from the portal's general statement ("tranne ... diversamente tutelati"). Stated as such in the document.
- Overture per-feature height provenance is not documented for Milan; I did not query data (no download).
- The first attempt at the GitHub docs requests was refused by a tool guard; I retried once with a plain URL. I also had one attempt using string concatenation that the guard denied and I did not repeat it.

## Open questions and risks
- **ESCALATION: Duomo position mismatch.** OSM centroid vs Wikidata P625: 83.3 m (threshold 50 m). The Wikidata point is at the west edge of the OSM footprint extent (lon 9.190578 vs OSM bounds 9.1906066 to 9.1926144), so it is probably a facade/entrance point, whereas the OSM centroid is the footprint centre, which matches ADR-0011's definition of a landmark position. As the card specifies, the origin in `DATA_SOURCES.md` is the OSM centroid (514978, 5034535). The orchestrator must confirm this origin before T-0.4 and later tasks depend on it.
- Licence compatibility: DBT (CC BY) next to ODbL tiles. Overture states CC BY 4.0 is compatible; attribution to Comune di Milano must be shown. Orchestrator to decide whether DBT heights are used (chain step 1).
- `UN_VOL_AV` semantics (eave vs ridge height) and the join between `UN_VOL` and `EDIFC` footprints are unverified.
- GitHub Pages: no docs statement about custom headers was found; ADR-0005 assumption remains unconfirmed.
- The Overture release changes monthly; the pipeline should pin the release.

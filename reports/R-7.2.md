## About dialog (what a user gets)
A button "Info" (IT) / "About" (EN) is the first item of the attribution line (`#about-button`, 44 px target, `aria-haspopup="dialog"`, `aria-expanded`). It opens a modal dialog (`role="dialog"`, `aria-modal`, labelled by its title) with: what the map is; the three sources (OpenStreetMap contributors, DBT 2020, comune boundary) each with what it is used for, licence link, date of the data and link to the source page; a line that the data were simplified, reprojected and converted and that colours, landmark details and fill trees are stylised; the build version (`<hash> <commit date>`); a link to the repository `https://github.com/alession-100/milano_iso` (from `docs/PROGRESS.md`). The overlay ends where the attribution band starts, so the attribution is never covered; the rest of the page is `inert` while it is open. Escape closes it from anywhere and focus returns to where it was; Tab leaves the dialog (no trap). It has its own IT/EN button because the toolbar is inert behind it. Every string is in `i18n.ts`; source names and licence names are data, as for the attribution.

Dates shown come from `docs/DATA_SOURCES.md`: OSM data up to 2026-11-14 (Geofabrik extract 261114); DBT 2020 flight March and April 2020; boundary resource last modified 2024-11-04.

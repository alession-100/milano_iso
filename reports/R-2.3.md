## Deviations and assumptions
- **Validator found a real error, fixed in `glb.py`.** The first run gave 105 `MESH_PRIMITIVE_ACCESSOR_UNALIGNED` errors, all on the uint16 `_FEATURE_ID` (stride 2). POSITION (stride 8) was already fine. Fix: a 2-byte id with byteStride 4 (2 bytes padding). Still ADR-0022 encoding; cost is small after gzip (total gzip-9 1,142,200 across 30 tiles). This answers the open byteStride/alignment question: stride 8 for POSITION and stride 4 for uint16 ids pass; no warnings. Indices are not vertex attributes and need no stride. `glb.py` was not on the card's edit list; edited because the card requires fixing validator errors.
- Summary artifacts moved from `reports/artifacts/T-2.2/` to `T-2.3/` (the exporter and `load-tiles.mjs` default) so `make tiles` does not modify committed T-2.2 files.
- `pytest -m data -k tiles` rewrites `reports/artifacts/T-1.6/validate_summary.md` via the existing conftest; I restored it with git checkout (out of scope).
- Attribution text: OSM "(c) OpenStreetMap contributors" (card, CLAUDE.md rule 10), licence "ODbL 1.0" (DATA_SOURCES rows 1/1b). DATA_SOURCES has no ready attribution sentence for the Comune; I composed it from the row 3b quoted page text: "Comune di Milano, DBT 2020, licenza Creative Commons Attribuzione 4.0 Internazionale (CC BY 4.0)". Orchestrator may want different wording.
- Manifest is compact JSON (no indentation), like the other JSON outputs. `bbox_local` z values use `0.0 - v` to avoid `-0.0`.
- The 256,000 budget is written as a literal (equal to the previous 250*1024).
- The "processed source counts" check covers rendered buildings only; flat layers are clipped per tile, so their counts are not comparable to the source.
- I did not run a sabotage test of the determinism check (a deliberate difference).
- The gltf-validator npm package version is a `dev` pre-release (2.0.0-dev.3.10), the latest tag published.

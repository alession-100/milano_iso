## What changed
Source (`web/`):
- `src/i18n.ts`: language state (`getLang`, `setLang`, `onLangChange`, `initialLang`, `?lang=`, `localStorage` key `milano-iso.lang`); `t(key)` reads the language in use; 10 new keys (language button, help panel).
- `src/toolbar.ts`: IT/EN button, Help button and panel, check boxes as 44 px rows, persistent notice live region, `applyLang` re-labels every string live; results list scrolls (max 220 px).
- `src/main.ts`: initial language, live re-labelling of the title, map label, notice, error and attribution; the notice lives in the toolbar's live region and has a 44 px close button.
- `src/modeToggle.ts`, `src/rotation.ts`: no inline styles; shared `.tb-btn` look (night look included); re-labelled live; mounted before the attribution (tab order).
- `src/pick/card.ts`, `src/pick/picker.ts`: card uses the shared UI variables, 44 px close button and link, top 108 px, re-fits under the toolbar zone and above the attribution and the debug overlay (resize observers), mounted before the attribution, follows the language.
- `src/debug.ts`: overlay at the bottom on narrow screens (does not cover the notice), strings through i18n.
- `src/dom.ts` (new): `mountBeforeAttribution`.
- `src/tiles/loader.ts`: a retry waits without a loader slot and only if the tile is still wanted.
- `index.html`: one UI stylesheet with day and night variables, focus ring, 44 px targets, attribution as 44 px links.

Tests (`web/`):
- `src/i18n.test.ts` (key parity, language state, grep-based "no UI string bypasses i18n" with a documented allow-list), `src/tiles/loader.test.ts` (2 new tests).
- `e2e/ui.spec.ts` (new, 24 tests): language, tab order and focus ring, escape and focus return, layout and 44 px targets (4 states x 8 combinations), touch emulation, reduced motion, accessible names and roles.
- `e2e/support.ts`: shared settle helpers (`waitForApp`, `settleTiles`, `frameRendered`, `settleRendered`, `stableCalls`, `setView`, `tilesState`) and the note that wall-clock thresholds do not belong in e2e. Used by `picking`, `toolbar`, `rotation`, `tiles`, `style`, `visual`, `smoke` and `daynight` specs.

Scripts (evidence, not in the test suite): `web/scripts/measure-contrast.mjs`, `capture-t54.mjs`, `compare-baselines.mjs`.

Docs: `docs/DECISIONS.md` ADR-0032, `docs/PROGRESS.md` (T-5.4 row, G3/G4 carry-overs marked resolved).

Baselines regenerated (win32 only; deleted first, then recreated): all 20 `web/e2e/visual.spec.ts-snapshots/*-win32.png` (close, default, default-rot1..3, info-card, night-close, night-default, west, wide; each at desktop and mobile) and both `web/e2e/toolbar.spec.ts-snapshots/*-win32.png`. The `*-linux.png` files were not touched and are stale.
